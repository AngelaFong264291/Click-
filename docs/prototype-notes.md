## 設計稿（docs/design/ocamp-design.html）
風格：大花紙 O'Camp。六款題型屬同一家族：白板題卡 + 卡紙作答區。

所有畫面都喺同一個 HTML 檔入面，分三組：
- 遊戲流程：01 首頁 → 02 大堂 → 03 作答（選項題）→ 04 揭曉 → 05 默契排名 → 06 結果
- 其餘五款題型：拉桿題、配對題、時間題、排序題、猜朋友題
- 大反應彈窗、分享圖、設計語言：彈窗（雙向奔赴、單戀）、07 分享圖、設計語言（色板、字體、元件）

- 呢個檔係設計參考，唔係可以直接用嘅 code：請將佢嘅顏色、字體、間距、圓角、陰影抽出嚟做 design tokens（CSS variables），再按 React 元件重寫。
- 設計稿只有中文版；英文介面跟同一套設計，文字由 `en.json` 提供（見提案「中英雙語介面」）。
