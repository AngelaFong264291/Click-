# data

`groups.json`、`adjectives.json`、`activities.json` 同 `templates.json` 係本地 JSON 詞庫。現有內容全部係**臨時樣本**，只用嚟驗證題目生成同計分；可以整批替換，唔代表正式題材或分類。

## 格式

- `groups.json`：每組有唯一 `id`、雙語 `name`，以及 `items` 陣列；每件物件有唯一 `id` 同中英文文字。題目選項引用物件 ID。
- `adjectives.json`：每個形容詞有唯一 `id`、中英文文字，以及 `groups` 陣列，列出適用嘅群組 ID。配對題只會抽出適用於該組嘅形容詞。
- `activities.json`：時間題可用嘅動作，每項有唯一 `id` 同中英文文字。
- `templates.json`：每個模板有唯一 `id`、`type` 同雙語 `text`。目前支援嘅 placeholder：選項題 `{item}`、拉桿題 `{item}` 同 `{adj}`、配對題 `{item}`、時間題 `{item}`、排序題 `{item}` 同 `{adj}`、猜朋友題 `{name}`。猜朋友題嘅 `{name}` 會保留到 UI 顯示時先代入目標玩家名字，不會寫入房間題目。

`item` 會按題型代入群組名稱、群組物件或活動；`adj` 會按所選群組抽取適用形容詞。模板中英文必須使用相同、而且該題型支援嘅 placeholders。可喺物件上加額外欄位（例如日後嘅標籤）；生成器只讀取必要欄位，因此唔需要因新增欄位而改生成器。

## 手動新增內容

1. 喺相應 JSON 陣列新增一筆，為每筆資料使用穩定且唯一嘅 `id`。群組 item 嘅 ID 亦要跨群組唯一。
2. 每個顯示文字都填好 `zh` 同 `en`；題目會按每位玩家自己揀嘅語言顯示。
3. 形容詞嘅 `groups` 只填現有群組 ID；每個可用配對題嘅群組至少要有 3 件物件同 3 個適用形容詞。可用於選項、猜朋友或排序題嘅群組至少要有 4 件物件。
4. 新增模板時只用該題型支援嘅 placeholders，並確保中英文兩邊用同一組 placeholders。每局需要 5 個不同選項題模板，其他題型各至少 1 個。
5. 跑 `npm test`。`src/data/data.test.js` 會指出重複 ID、缺少翻譯、無效群組連結、模板 placeholder 錯誤或題庫不足；生成器亦會喺開局前對不足內容提供清楚錯誤。

正式內容可以完全取代目前樣本，但要保留以上資料形狀同最低數量要求。
